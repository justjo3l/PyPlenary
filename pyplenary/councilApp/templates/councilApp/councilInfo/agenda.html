Agenda Editor

Admin how-to

Create one day for a single-day agenda, or multiple days if council runs across more than one day. If there is only one day, the public page hides the day tabs automatically.

Day title is the tab label, Date is the date text shown above the timeline, and Order controls which day appears first. Lower numbers appear first.

Time appears beside the agenda entry, Title is the main heading, Color controls the timeline dot and badge colour, and Order controls item position within the day.

Badge is a short coloured pill beside the title, useful for labels like Vote, Break, Closed, Workshop, or Action. Category is a neutral tag for grouping, such as Governance, Policy, Welfare, or Training.

Content supports markdown for the agenda description. Links supports one markdown link or plain URL per line. Make all changes first, then use the single save button at the bottom.
